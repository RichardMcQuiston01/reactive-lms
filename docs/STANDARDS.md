# Standards

Exact specification versions ReactiveLMS targets.

| Standard | Version / edition |
| --- | --- |
| SCORM 1.2 | SCORM 1.2 |
| SCORM 2004 | SCORM 2004 4th Edition (CAM 1.3) |
| xAPI | xAPI 1.0.3 |
| cmi5 | cmi5 Quartz 1st Edition |
| LTI Advantage | LTI 1.3 + AGS 2.0 + NRPS 2.0 + DL 2.0 |
| H5P | H5P package spec |
| LIS | LIS 2.0.1 as the information model |

Also supported as non-standard packaged content:

- HTML5 static bundles (ZIP + optional `index.html`)
